Burp Suite proxy

Send this browser’s HTTP and HTTPS traffic through Burp’s proxy listener. Settings stay on your device.

Enabling this routes browser traffic through Burp. Burp must be running, and you need the Burp CA trusted in Chrome for HTTPS to work.

Proxy off

Quick setup

  1. Start Burp Suite and open Proxy → Proxy settings.
  2. Confirm a listener on 127.0.0.1:8080 (or match the host/port above).
  3. Install and trust the Burp CA in Chrome so HTTPS can be intercepted.
  4. Press Use Burp here. Press Disable proxy when you are done.

Localhost and loopback addresses are bypassed so Chrome internals keep working.

100% local. No tracking.
